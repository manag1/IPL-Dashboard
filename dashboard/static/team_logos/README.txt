TEAM LOGOS
==========

Place team logo PNG files in this folder. The dashboard automatically looks for:

  <slug>.png

where the slug is the lowercase team name with spaces/punctuation converted to hyphens.

Examples:
  Chennai Super Kings       -> chennai-super-kings.png
  Mumbai Indians            -> mumbai-indians.png
  Royal Challengers Bengaluru -> royal-challengers-bengaluru.png
  Kolkata Knight Riders     -> kolkata-knight-riders.png
  Delhi Capitals            -> delhi-capitals.png
  Rajasthan Royals          -> rajasthan-royals.png

If a logo is not present, the dashboard automatically shows a small initials badge instead.
